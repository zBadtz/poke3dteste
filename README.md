# Pixel Remaster

Seguir prompt 2 anexado, com imagens anexadas como referência da aparência do jogo, como vídeo e imagens coladas no prompt.
Menu do jogo deve possuir animação como do jogo pokemon fire red original, com a logo original e etc, Deve seguir e pegar todos os arquivos necessários do jogo original (repositório no prompt)

faça as perguntas que desejar para a construção do projeto (ignorar perguntas presentes no prompt) faça novas que precisar.
